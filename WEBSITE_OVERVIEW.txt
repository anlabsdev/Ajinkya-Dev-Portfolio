--------------------------------------------------------------------------------
1. WHAT THIS SITE IS
--------------------------------------------------------------------------------
A personal portfolio + product-studio showcase for Ajinkya Narke (Software
Engineer / AI Software Builder). Built as a React SPA with a 3D-animated
homepage (drag-to-rotate island scene), and content pages for projects,
the ANlabs studio, certifications, an AI chatbot demo, and contact/connect
forms.

--------------------------------------------------------------------------------
2. TECH STACK
--------------------------------------------------------------------------------
- React 18 + Vite 4 (dev server on :5173)
- React Router DOM v6 (route-based code splitting via React.lazy)
- Tailwind CSS (darkMode: 'class', custom primary/secondary palette)
- Three.js + @react-three/fiber + @react-three/drei (3D scenes)
- Framer Motion (page transitions, scroll reveals, nav menu)
- styled-components, react-icons, react-vertical-timeline-component
- EmailJS (contact form), react-error-boundary (WebGL fallback safety)
- Deployed on Vercel (vercel.json present)

4. RECENT CHANGES MADE THIS SESSION
--------------------------------------------------------------------------------
a) Reveal-on-scroll (src/components/Reveal.jsx)
   Wraps section content in a Framer Motion fade/slide-up that triggers via
   whileInView. Applied across About/Projects/etc. section blocks.

b) Scroll progress bar (src/components/ScrollProgress.jsx)
   Fixed 3px gradient bar at the very top of the viewport (z-110), filling
   left-to-right based on page scroll position. Mounted globally in
   App.jsx so it shows on every route.

c) About-page 3D moment (src/components/AboutScene.jsx)
   A contained 260/320/380px-tall card reusing the existing "low poly man
   working at a table with a laptop" model (already used on /contact, so
   the browser reuses the cached .glb instead of fetching a new asset).
   Wrapped in drei's PresentationControls for a subtle, limited-range
   tilt-on-drag interaction (not a full 360 spin -- kept restrained to
   match the site's professional tone). Includes an "Open to work" pill
   badge tying back to the About copy.

d) Page transition (src/App.jsx)
   Flattened the previous nested <Routes> structure into one flat,
   location-keyed <Routes> wrapped in AnimatePresence. Every route change
   now does a ~220ms fade + 14px vertical slide instead of an instant
   swap. Footer is rendered outside the animated wrapper (shown on every
   route except Home).

7. VISUAL AUDIT -- ISSUES FOUND (via real headless-browser screenshots)
--------------------------------------------------------------------------------
Reviewed at 1440px desktop width across Home, About, Projects, Studio,
Certification, Connect, Contact.

[HIGH] Contact page 3D model panel renders badly oversized
  File: src/pages/Contact.jsx (~line 155)
  The model card wrapper is `lg:h-auto` inside a `min-h-screen` flex row
  with default `align-items: stretch`. At the `lg` breakpoint this makes
  the 3D panel stretch to the FULL section height (which is >= 100vh)
  instead of staying a contained card like it is on mobile/tablet
  (h-[260px]/[360px]/[460px]). The result: the laptop/face/desk model
  renders zoomed-in and oddly cropped, with a large dead/blank brown
  "desk" area filling the rest of the panel. This is a real, reproducible
  bug at any normal desktop window height, not just a screenshot artifact.
  FIX: replace `lg:h-auto` with a fixed cap (e.g. `lg:h-[520px]`) or add
  `lg:self-start` / `lg:items-start` on the parent flex container so the
  panel stops stretching to match section height.

[MEDIUM] Home page navbar contrast against the sky scene
  File: src/components/Navbar.jsx + src/pages/Home.jsx
  The desktop nav links use light/white-ish text with no backdrop, sitting
  directly over the Home page's bright light-blue-and-white-cloud 3D sky.
  Links like "Studio" visually blend into passing white cloud shapes,
  hurting legibility right at the most important first-impression page.
  FIX: add a subtle scrim behind the header on Home only (e.g. a
  bg-gradient-to-b from-black/20 strip behind the nav row), or switch nav
  text to a darker/higher-contrast color specifically on the home route.

[LOW] Studio/Certification/Connect pages have a lot of unstyled dead space
  This was partly a screenshot-height artifact, but worth a real look --
  Studio and Certification end fairly early on a real screen vs. Home/About
  which are denser. Not a bug, but a chance to add a closing section (e.g.
  a "what I'm building next" teaser or testimonials) on Studio/Certification
  so the page doesn't feel like it runs out of content early on tall
  monitors.

[NOTE] Dark mode is the default on first visit for most users
  ThemeContext defaults to the OS's prefers-color-scheme. Most of this
  audit was captured in dark mode as a result. Worth doing a dedicated
  pass in LIGHT mode too to confirm contrast/shadows hold up there (the
  card shadow values like `shadow-[0_18px_45px_rgba(15,23,42,0.06)]` were
  clearly tuned for light backgrounds and may look flat in dark mode).
